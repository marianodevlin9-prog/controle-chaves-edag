# Controle de Chaves - EDAG

Sistema web desenvolvido para o gerenciamento e controle de chaves do departamento de facility management.

👉 **[Acessar o Sistema Online](https://marianodevlin9-prog.github.io/controle-chaves-edag/)**

## Funcionalidades
* Registro de retirada e devolução de chaves.
* Identificação rápida por salas/setores.
